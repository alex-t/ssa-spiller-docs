# Weekly Report — 2026-05-26 to 2026-06-05

## Summary

Completed SSA destruction + operand rewrite phase. The SSA Register Allocator

## Completed

### Splitter Removal (May 26)
- Removed ~330 lines of LR splitting infrastructure (ShadowMap, planSplit,
  commitPlan, gap-filling, recoloring). Width-descending coloring already
  reuses freed register slots at def points, making the splitter redundant.
- All 12 tests pass without it. Renamed `colorAndSplit()` to `color()`.
- Removed unused members: TII, MLI, Indexes, ST.

### Documentation Overhaul (May 26-27)
- Renamed docs folder `SSA_Spiller/` → `SSARA/`.
- Created `04-Design/SSA_RA_Coloring.md` — comprehensive coloring design doc
  with mermaid diagrams, correctness argument, and design decisions.
- Updated concept docs (Chordal_Graphs.md, PEO.md), README, SHARED_CONTEXT,
  pipeline docs.

### SSA Destruction + Operand Rewrite (Jun 1-5)
- Designed and implemented combined pass (~300 new LOC):
  - `lowerPHIs()`: worklist-based chain/cycle permutation decomposition
  - `resolvePermutation()`: SrcRefCount for fan-out correctness, worklist for chains
  - Three-tier cycle breaking: scratch reg (width-matched) → V_SWAP_B32 (GFX9+) → XOR triplet
  - Critical edge splitting on demand
  - `rewriteOperands()`: vreg→physreg with subreg composition
  - `destroySSAAndRewrite()`: precondition guard for SI pseudos, calls leaveSSA + invalidateLiveness

### PHI Liveness Finding (Jun 5)
- Discovered LLVM's LiveIntervalCalc extends PHI uses to `getMBBEndIdx(PredMBB)`,
  not into the PHI block. PHI sources are never live inside the PHI block.
- Removed unnecessary PHI false-interference fix loop (was a no-op).
- The only fix needed: `if (MI.isPHI()) continue;` before kill tracking —
  prevents double-freeing physregs shared with just-colored PHI results.

### Bug Fixes (Jun 3-5)
- Scratch register width: must match cycle's register width (not always 32-bit).
  Use `getMatchingSuperReg` for wide tuples, increment MaxIdx by CycleWidth.
- emitSwap infinite recursion: base case checks `getRegSizeInBits <= 32` instead
  of `getRegSplitParts` emptiness.
- MaxHWLimit: changed to `ST->getMaxNumVGPRs(MF)` to respect `amdgpu-num-vgpr`.
- DenseMap::erase() returns void: worklist pattern for chain resolution.

### Testing (Jun 4-5)
- 5 new SSA destruction tests:
  - `destruct-simple-copy`: COPY on one edge, identity on other
  - `destruct-identity`: all identities, no copies
  - `destruct-swap`: 32-bit cycle via scratch register
  - `destruct-rewrite`: straight-line operand rewrite
  - `destruct-wide-swap`: 128-bit swap (gfx900→V_SWAP_B32, fiji→XOR)
- Created test documentation: `05-Testing/SSA_RA/SSA_RA_TEST_PATTERNS.md`
- Total: 17 tests passing (12 coloring + 5 destruction)
