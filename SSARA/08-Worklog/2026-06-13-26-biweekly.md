# Biweekly Report — June 13–26, 2026

_(Second week, June 22–26, was vacation; work below spans June 13–18.)_

## SSA Register Allocator

### RebuildSSA
- Fixed reaching-def mis-attribution in `reachedByThisVNI`: replaced the position/dominance
  heuristic with an exact `LI.getVNInfoBefore(useSlot) == VNI` query. The old logic attributed
  post-redefinition uses to the wrong value, keeping a loop induction variable live past its
  update and forcing a spurious back-edge copy.
- **Refactored `AMDGPURebuildSSA` to use `MachineLaneSSAUpdater`** (Phase 1, complete + committed).
  Replaced ~250 lines of bespoke inline SSA repair (`buildRealPHI`, `splitNonPhiValue`,
  `rewriteUses`, `extendAt`, `reachedByThisVNI`, …) with `repairSSAForNewDef`. Removed the
  `MachineLoopInfo` dependency. This eliminates the root cause of the partial-wide-def bug: the
  inline path legalized in-place subregister defs inconsistently, leaving a partial wide def
  (`undef %r.sub0:vreg_64`) so a tuple carried one live lane but the RA allocated the full pair —
  inflating pressure and causing loop-coloring aborts / verifier errors. The lane-aware updater
  never emits this.

### Coloring
- **Function-wide width-descending coloring**: swapped the `color()` loop nesting to
  outer=width-descending, inner=MBB (MDT pre-order), so all wider defs are committed to
  `ColorMap` before narrower passes run. This prevents narrow defs from fragmenting the
  alignment slots wider tuples need (e.g. a `VGPR_32` at an odd index blocking an even-aligned
  `VReg_64` pair on gfx90a). Cross-width interference handled by `seedOccupiedAtBBEntry`
  (wider live-ins), a per-block `WiderDefs` pre-scan (within-block wider defs), and a `ColorMap`
  overlap scan in `pickFreePhysReg` (cross-block wider entries). Test `align-fragmentation.mir`
  (gfx90a) saves 1 VGPR. Follow-up: replace the O(|ColorMap|) scan with an interval tree
  (O(log N + k)) before large-kernel testing.

### SSA Destruction (PHI lowering)
- Derive the register file **per cycle** in `resolvePermutation` (from `CycleStart`) instead of a
  block-wide `IsVGPR` from the first PHI. Fixes a latent miscompile (wrong-file scratch/swap) for
  mixed VGPR/SGPR PHI blocks containing a same-file permutation cycle.
- Honor the **subregister index on PHI source operands** in `lowerPHIs`. Previously a PHI source
  like `%x.sub0` (tuple colored to an SGPR pair) lowered to an illegal 64→32-bit copy.

### SSA Spiller
- **Proportional spill margin** corrected from `(N*9)/10` to `N - N/10` (true floor-10%); reserve
  SGPR-spill WWM VGPRs only when SGPRs are actually spilled.
- **During-MI peak register-pressure metric** (root-cause fix). The spiller measured the
  after-instruction live set, which undercounts the true peak when operands die in place — a
  multi-input/early-clobber instruction with a value live across it needs more registers while
  executing than survive it, producing `FINAL RP VALIDATION FAILED` / RA aborts on feasible
  budgets. Switched to `reset(MI); recede(MI); getMaxPressure()` with a PHI guard (a PHI has no
  read phase).
- **Lane-granular spill-candidate selection**: rank at MI's own slot and subtract the lanes MI
  reads per register, keeping a sub-register spillable when a sibling lane of the same tuple is
  read here (subsumes the early-clobber special case).
- **`fixPathologicalPHIs` dead-PHI fix**: after the RebuildSSA refactor, a loop-invariant spilled
  value's PHI at the loop header can become unused (uses rewritten to a closer reload). The code
  unconditionally replaced it with a dead `SI_SPILL_V32_RESTORE` that still consumed a VGPR and
  pushed the loop over budget. Now check `use_nodbg_empty(PHIDest)` and delete the dead PHI
  silently instead.
- **Final-RP verifier made an option**: replaced the always-on `report_fatal_error` with
  `-amdgpu-ssa-spiller-verify-rp` (`boolOrDefault`, on by default under `EXPENSIVE_CHECKS`),
  forced on for the spiller suite via a `lit.local.cfg` substitution.

  refactor landed**. Final: 78 tests (36 SSARA + 42 SSASpiller), 0 unexpected failures.

### Investigation / Design
- Established the **spiller↔RA pressure-model agreement** principle: a spiller "feasible" result
  the RA cannot color is a bug.
- Corrected register-file facts: VGPR tuples are stride-1 (any consecutive regs, not aligned);
  only SGPRs are alignment-constrained (stride 2/4).
- Analyzed cross-block fragmentation and **function-wide vs per-block** width-descending coloring;
  concluded coalescing must stay a post-RA quality pass while fragmentation robustness needs
  alignment-aware pressure or function-wide coloring.
