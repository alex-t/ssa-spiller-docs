• Contributions from AlexanderT

    • SSA Register Allocator

      • Function-wide width-descending coloring: reordered coloring so all wider register defs across the whole function are colored before any narrower ones. This prevents a narrow value from fragmenting an alignment slot a wider tuple needs (e.g. a 32-bit value at an odd index blocking an even-aligned 64-bit pair on gfx90a), saving registers in mixed-width kernels.
      • PHI lowering — per-cycle register file: resolvePermutation chose the register file once from the first PHI of a block, but a block can hold both VGPR and SGPR PHIs. It now derives the file per permutation cycle, fixing a latent wrong-file scratch/swap miscompile.
      • PHI lowering — subregister sources: lowerPHIs dropped the subregister index on PHI source operands, emitting an illegal 64→32-bit copy (e.g. %x.sub0 of an SGPR pair). It now copies the correct sub-register.

    • RebuildSSA

      • Reaching-def fix: corrected use→value attribution with an exact “value-number-before-use” query, removing a spurious back-edge copy on loop induction variables.
      • Refactor onto MachineLaneSSAUpdater: replaced ~250 lines of bespoke SSA reconstruction with the shared lane-aware updater (repairSSAForNewDef). This removes a class of bugs where in-place sub-register defs were legalized into a partial wide def — a tuple carrying one live lane while the allocator reserved the full pair, inflating register pressure. It had caused loop-coloring failures and a 128-bit verifier error, both now fixed.

    • SSA Spiller

      • Pressure measured at the instruction peak: the spiller used the after-instruction live set, which undercounts when operands die in place (multi-input or early-clobber instructions with a value live across them), so feasible budgets were aborting. It now uses the during-instruction peak, with PHIs handled specially (no read phase). A kernel at amdgpu-num-vgpr=3 that previously aborted now allocates.
      • Lane-precise spill candidates: spill selection now excludes the lanes read by the current instruction, so a sub-register stays spillable when a sibling lane of the same tuple is read — subsuming the old early-clobber special case.
      • Spill-margin correction: the budget margin is now a true 10% floor, so small but satisfiable budgets are targeted exactly instead of being cut 25–50%.
      • Dead-PHI cleanup: a loop-invariant spill could leave an unused PHI that was being replaced by a dead reload occupying a VGPR; it is now deleted instead.
      • RP self-check behind a flag: the final register-pressure verifier is now -amdgpu-ssa-spiller-verify-rp (on by default in expensive-checks builds, and enabled across the spiller test suite) instead of an always-on fatal check.

    • Pipeline Integration & Testing

      • End-to-end test suite (4 tiers) covering RebuildSSA → SSA Spiller → SSA RA: CFG shapes, spilling (with checks proving the SSA spiller produced the spill), register widths (including MFMA/AGPR on gfx908), and target features (SGPR-heavy, occupancy).
